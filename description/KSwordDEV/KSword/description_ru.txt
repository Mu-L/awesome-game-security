KSword — это комплексный набор инструментов для анализа систем Windows и безопасности игр, построенный вокруг графического интерфейса на базе Qt с поддержкой пользовательского драйвера ядра. Он предлагает модульные стыкуемые панели для просмотра и изменения процессов, объектов ядра, памяти, драйверов, callback-функций, SSDT-хуков, сетевого трафика, дампов сбоев и артефактов файловой системы. В состав входят монитор Win32 API с inline-хукингом, интеграция плагинов Cheat Engine, управление оконным слоем DWM и онлайн-сканирование вредоносного ПО через VirusTotal и ThreatBook. Написан в основном на C++ и предназначен для специалистов по реверс-инжинирингу, исследователей античит-систем и аналитиков безопасности, изучающих внутреннее устройство Windows и механизмы защиты игр.
