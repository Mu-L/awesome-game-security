KSword は、Qt ベースの GUI とカスタムカーネルドライバーを基盤とした、包括的な Windows システム解析およびゲームセキュリティ向けツールキットです。プロセス、カーネルオブジェクト、メモリ、ドライバー、コールバック、SSDT フック、ネットワークトラフィック、クラッシュダンプ、ファイルシステムの痕跡を調査・操作するための、モジュール式ドッキングパネルを提供します。インライン フックによる Win32 API モニター、Cheat Engine プラグイン連携、DWM ウィンドウレイヤー制御、VirusTotal および ThreatBook によるオンラインマルウェアスキャンなどの関連コンポーネントも含まれます。主に C++ で記述されており、リバースエンジニア、アンチチート研究者、Windows 内部構造やゲーム保護機構を調査するセキュリティアナリストを対象としています。
