FairCount 是一款 Minecraft Fabric 模組，透過要求用戶端在加入多人伺服器時回報已載入的模組，在伺服器端強制執行模組與資源包白名單。此模組以 Java 編寫，適用於 Fabric Loader 與 Fabric API，會盤點獨立的 JAR 以及嵌套的 jar-in-jar 模組，驗證 SHA-256 雜湊以偵測已核准模組是否遭篡改，並對未安裝此模組或使用未獲允許用戶端附加內容的玩家斷線。它亦會以類似的白名單與雜湊檢查監控外部資源包，自動允許 Fabric API 模組，並提供管理員指令與本地化的踢出訊息。此模組面向需要在競技 PvP、活動與接近原版公平玩法情境中進行反作弊式用戶端完整性強制的伺服器管理員。
