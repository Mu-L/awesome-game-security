FairCount는 멀티플레이 서버 접속 시 클라이언트가 로드된 MOD를 보고하도록 요구함으로써 서버 측 MOD 및 리소스 팩 화이트리스트를 강제하는 Minecraft Fabric MOD입니다. Java로 작성되어 Fabric Loader와 Fabric API용으로 독립형 JAR과 중첩된 jar-in-jar MOD를 재고 조사하고, 승인된 MOD의 변조 버전을 탐지하기 위해 SHA-256 해시를 검증하며, MOD가 없거나 허용되지 않은 클라이언트 추가 항목을 사용하는 플레이어를 연결 해제합니다. 또한 유사한 화이트리스트 및 해시 검사로 외부 리소스 팩을 모니터링하고, Fabric API 모듈을 자동으로 허용하며, 관리자 명령과 현지화된 추방 메시지를 제공합니다. 이 MOD는 경쟁 PvP, 이벤트, 바닐라에 가까운 공정한 플레이를 위해 치트 방지형 클라이언트 무결성 강제가 필요한 서버 관리자를 대상으로 합니다.
