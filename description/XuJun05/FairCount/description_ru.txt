FairCount — это мод Minecraft для Fabric, который обеспечивает серверные белые списки модов и наборов ресурсов, требуя от клиентов сообщать о загруженных модах при подключении к многопользовательскому серверу. Написанный на Java для Fabric Loader и Fabric API, он инвентаризирует автономные JAR и вложенные jar-in-jar моды, проверяет хеши SHA-256 для обнаружения подменённых версий одобренных модов и отключает игроков, у которых нет мода или которые используют запрещённые клиентские дополнения. Он также контролирует внешние наборы ресурсов с аналогичными проверками белого списка и хеша, автоматически разрешает модули Fabric API и предоставляет административные команды и локализованные сообщения об отключении. Мод предназначен для администраторов серверов, которым нужно принудительное обеспечение целостности клиента в стиле античита для соревновательного PvP, событий и честного ванильного геймплея.
