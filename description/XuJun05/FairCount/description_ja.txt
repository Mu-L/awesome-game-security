FairCount は、マルチプレイサーバーへの参加時にクライアントへ読み込み済みの MOD を報告させることで、サーバー側の MOD およびリソースパックのホワイトリストを強制する Minecraft Fabric MOD です。Java で記述され、Fabric Loader と Fabric API 向けに、スタンドアロンの JAR およびネストされた jar-in-jar MOD を棚卸しし、承認済み MOD の改ざん版を検出するために SHA-256 ハッシュを検証し、MOD が無い、または許可されていないクライアント追加を使用しているプレイヤーを切断します。また、同様のホワイトリストおよびハッシュチェックで外部リソースパックを監視し、Fabric API モジュールを自動的に許可し、管理者コマンドとローカライズされたキックメッセージを提供します。この MOD は、競技 PvP、イベント、バニラに近い公平なゲームプレイのために、反チート型のクライアント整合性強制を必要とするサーバー管理者を対象としています。
