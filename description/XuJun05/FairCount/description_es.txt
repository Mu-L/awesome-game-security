FairCount es un mod de Minecraft para Fabric que aplica listas blancas del lado del servidor para mods y paquetes de recursos, exigiendo que los clientes informen de sus mods cargados al unirse a un servidor multijugador. Escrito en Java para Fabric Loader y Fabric API, inventaria JAR independientes y mods jar-in-jar anidados, verifica hashes SHA-256 para detectar versiones manipuladas de mods aprobados, y desconecta a los jugadores que no tengan el mod o usen complementos de cliente no permitidos. También supervisa paquetes de recursos externos con comprobaciones similares de lista blanca y hash, permite automáticamente los módulos de Fabric API, y proporciona comandos de administración y mensajes de expulsión localizados. El mod está dirigido a administradores de servidores que necesitan una aplicación de integridad del cliente al estilo anti-cheat para PvP competitivo, eventos y una experiencia de juego justa y cercana al vanilla.
