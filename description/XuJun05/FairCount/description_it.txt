FairCount è una mod Minecraft Fabric che applica whitelist lato server per mod e resource pack, richiedendo ai client di segnalare le mod caricate quando si uniscono a un server multigiocatore. Scritta in Java per Fabric Loader e Fabric API, inventaria JAR autonomi e mod jar-in-jar annidati, verifica hash SHA-256 per rilevare versioni manomesse di mod approvate, e disconnette i giocatori che non possiedono la mod o utilizzano aggiunte client non consentite. Monitora anche resource pack esterni con controlli simili di whitelist e hash, consente automaticamente i moduli Fabric API, e fornisce comandi amministrativi e messaggi di espulsione localizzati. La mod è destinata agli amministratori di server che necessitano di un'applicazione dell'integrità del client in stile anti-cheat per PvP competitivo, eventi e un gameplay equo simile al vanilla.
