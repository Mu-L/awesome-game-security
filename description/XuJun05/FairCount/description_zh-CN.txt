FairCount 是一个 Minecraft Fabric 模组，通过要求客户端在加入多人服务器时上报已加载的模组，在服务端执行模组与资源包白名单。该模组使用 Java 编写，面向 Fabric Loader 与 Fabric API，会清点独立的 JAR 以及嵌套的 jar-in-jar 模组，校验 SHA-256 哈希以检测已批准模组是否被篡改，并对未安装该模组或使用未获允许客户端附加内容的玩家执行断开连接。它还会以类似的白名单与哈希校验监控外部资源包，自动放行 Fabric API 模块，并提供管理员命令与本地化的踢出消息。该模组面向需要在竞技 PvP、活动与接近原版公平玩法场景中进行反作弊式客户端完整性管控的服务器管理员。
